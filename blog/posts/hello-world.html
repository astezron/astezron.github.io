Why geology needs spatially aware machine learning

September 2026 · 5 min read

Most machine learning algorithms assume samples are independent. Drillhole data is anything but: two assays a metre apart usually tell a very similar story. This short post is a placeholder — replace it with your own writing.

The problem with independence

If a classifier sees each sample in isolation, it throws away the spatial continuity that a variogram would describe in one picture.

Tobler's first law: everything is related to everything else, but near things are more related than distant things.

A geostatistical remedy

Adding features derived from kriging or simulation lets a model like XGBoost "see" neighbourhood information:

features = np.column_stack([
    raw_assays,
    kriged_proxy,        # smooth local estimate
    sim_prob_class_k,    # probability from simulations
])
model = xgb.XGBClassifier(objective="multi:softprob").fit(features, labels)
